# Mirrora Website

Premium investor-first website for Mirrora, an AI fashion commerce platform.

## Current version

This first production-ready prototype is a static website contained in `index.html`.

It includes:

- luxury investor-first homepage;
- market opportunity section;
- problems we solve section;
- solution flow;
- two business directions;
- business model;
- web demo platform preview;
- mobile app experience preview;
- brands section;
- investors section;
- contact / waitlist form prototype;
- language dropdown;
- responsive layout.

## Vercel settings

Use these settings when importing the repository into Vercel:

- Framework Preset: Other
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist

## Notes

The current version is static by design so it can be deployed quickly and reliably. Later it can be migrated into a full React/Vite or Next.js application once the visual direction is approved live.
